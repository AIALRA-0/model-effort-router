# 本地统计与隐私协议

## 1 采集目的

本 Skill 记录真实项目迭代的路线和结果，用于判断现有启发式是否长期造成过度路由、欠路由、返工或范围漂移

记录不会用于重建用户对话、代码内容或项目身份

## 2 授权流程

本地统计安装后保持关闭

用户运行以下命令会创建本机授权标记和随机化名盐

```powershell
# 明确启用仅限本机的元数据采集，不启用任何网络上传
python scripts/telemetry.py enable --pretty
```

用户可以停止后续采集，同时保留既有记录

```powershell
# 停止新记录，已有本地数据保持不变
python scripts/telemetry.py disable --pretty
```

用户可以删除统计目录

```powershell
# 精确确认后只删除 model-effort-router 的本地统计目录
python scripts/telemetry.py purge --confirm PURGE-LOCAL-TELEMETRY --pretty
```

环境变量 `MODEL_EFFORT_ROUTER_TELEMETRY=off` 是紧急停止开关

## 3 允许字段

允许记录的字段分成6组

- 路线：策略、任务类别、推荐模型、实际模型和推理档位
- 任务条件：风险等级、验证强度和上下文模式
- 时间：开始时间、结束时间和持续秒数
- 验收：接受状态、严重缺陷、回归、范围违规和已验证失败假设数
- 用量：宿主真实提供的令牌和工具调用计数，以及计数来源
- 工作树：Git 仅返回修改文件数量、增加行数和删除行数

项目和机器标识由本机随机盐生成 HMAC-SHA-256 化名

HMAC-SHA-256 是带秘密盐的哈希计算，它让同一项目在本机保持稳定分组，同时避免把原始路径写入记录

## 4 禁止字段

以下内容不能写入记录或公开快照

- 用户提示词、对话和模型输出
- 代码、差异、日志、错误文本和测试名称
- 文件名、文件路径、仓库网址、分支名和提交摘要
- 个人、组织、账户、设备和网络标识
- 密钥、令牌、Cookie、连接字符串和内部链接
- 自由文本备注

命令行参数只接受受控分类值和非负计数，避免自由文本意外进入数据集

## 5 未知值

宿主没有提供令牌、推理令牌或工具调用计数时，脚本保存 `null`

`measurement_source` 同时记录 `host_reported`、`transcript_counted`、`estimated` 或 `unavailable`

估计值与宿主实测值在分析时必须分开

## 6 整机快照

`snapshot` 读取同一机器的全部本地运行记录，并按照任务类别、模型和推理档位汇总

快照移除项目化名、机器化名和精确时间，只保留观察日期范围和聚合分组

公开分组少于 `public_export_minimum_group_size` 时，只显示样本数量并隐藏接受率、范围违规率和回归率

## 7 数据边界

脚本不包含网络客户端和上传端点

用户主动复制、提交或上传本地原始记录会改变隐私边界，默认工作流只允许公开 `snapshot` 产生的聚合文件
